# PetalTalk v1.0.0
A light-weight, open-source app that adds a PNGTuber on your screen for both you to see or for streams/recordings

## ✨ Features

- Voice Activation: Real-time lip-syncing based on microphone input.
- Always on Top: Keeps your avatar visible over games and other windows.
- OBS Mode: Built-in green screen support for high-quality Window Capture in OBS.
- Preset System: Save and load different character setups, sizes, and positions.
- Lightweight: Minimal CPU/RAM impact, perfect for high-performance gaming.
- Transparent Background: Seamlessly integrates into your stream layout.
